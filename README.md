## 📲 Tải ứng dụng Android (APK)

Bạn có thể tải file APK cài đặt trực tiếp về điện thoại để sử dụng lâu dài:

👉 **[Tải file APK mới nhất tại GitHub Releases](https://github.com/vithao-gihub/treth-vthao/releases/latest)**

### Cách cài đặt trên điện thoại:
1. Nhấp vào đường dẫn trên và tải file `TreTH-v4.0.0.apk` về điện thoại.
2. Mở file APK vừa tải và chọn **Cài đặt**.
3. Nếu máy hỏi quyền bảo mật, chọn **Cho phép cài đặt ứng dụng từ nguồn này**.
4. Ứng dụng đã sẵn sàng trên màn hình chính!

## ✨ Tính năng nổi bật

- 📝 **Quản lý công việc đa năng:**
  - 4 chế độ xem linh hoạt: **Danh sách (List)**, **Ma trận Eisenhower**, **Bảng Kanban** và **Lịch (Calendar)**.
  - Tách biệt rõ ràng việc đang làm và đã hoàn thành; hỗ trợ tìm kiếm và lọc thông minh.
  - Thêm việc nhanh gọn, tiện lợi (Progressive Disclosure).
- ⏱️ **Đồng hồ Pomodoro:** Hỗ trợ chu kỳ tập trung chuẩn khoa học, đếm ngược âm thanh và thống kê chi tiết.
- 🌱 **Theo dõi thói quen (Habit Tracker):** Điểm danh thói quen hàng ngày, trực quan và dễ duy trì động lực.
- 📓 **Ghi chú nhanh (Notes):** Hỗ trợ ghi chú định dạng thẻ, lọc theo chủ đề.
- 📊 **Module Thống kê chuyên sâu:** Biểu đồ hình tròn SVG thuần không phụ thuộc thư viện ngoài, phân tích theo Trạng thái, Loại việc và Ma trận Eisenhower.
- 💾 **Bảo mật & Ngoại tuyến (100% Offline):** Dữ liệu lưu trữ an toàn trong máy, hỗ trợ sao lưu và phục hồi qua JSON / Excel (.xlsx).
- 🎨 **Giao diện tối ưu:** Tối ưu hóa rendering, cuộn trang 60fps mượt mà, hỗ trợ cả Chế độ Tối (Dark Mode) và Chế độ Sáng (Light Mode).

## 🛠️ Công nghệ phát triển

- **Frontend:** 100% Vanilla JavaScript (ES6+), HTML5, CSS3 thuần.
- **Mobile Runtime:** Apache Capacitor 6 (Android native bridge).
- **CI/CD:** GitHub Actions tự động biên dịch và phát hành file APK mỗi khi cập nhật mã nguồn.

## 💻 Hướng dẫn chạy thử trên máy tính (Local)

1. Sao chép dự án:
   ```bash
   git clone https://github.com/vithao-gihub/treth-vthao.git
   cd treth-vthao
   ```
2. Mở trực tiếp file `index.html` trên trình duyệt bất kỳ hoặc sử dụng Live Server.
