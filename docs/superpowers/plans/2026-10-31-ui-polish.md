**Goal:** Transform TreTH interface into a clean, sharp, professional productivity tool matching Linear/Notion/Todoist aesthetics by removing decorative clutter/emojis, adopting a neutral color palette, tightening border radii and task cards with hover actions, while preserving 100% of underlying JavaScript functionality.

**Architecture:** Pure CSS, SVG icon, and text layer refactoring without modifying any functional IDs, event handlers, or state management logic. Changes in the project root are mirrored 1:1 to `www/`. Automated Headless Chrome tests verify DOM styling, typography, hover visibility, and zero functional regression.

**Tech Stack:** Vanilla JavaScript (ES6+), HTML5, CSS3, Headless Chrome (Python testing harness).

## Global Constraints

- Absolutely NO changes to JavaScript application logic (view switching, dark mode, filter logic, drag-and-drop, data storage, or view-mode classes).
- Keep 100% of functional IDs and classes intact.
- Zero external CSS/JS framework dependencies.
- Every root file change (`index.html`, `script.js`, `style.css`, `styles/`) MUST be synchronized with its counterpart in `www/`.
- Automated headless browser tests must pass with 100% evidence before completion.

## Review Focus

1. Dropdown options in `<select>` elements: ensure value attributes and change handlers continue firing accurately after emojis are removed.
2. Quick-add input: verify shortcuts (`!`, `#`, date parsing) still work seamlessly with the new compact placeholder.
3. Hover actions on task cards: ensure buttons are still touch-accessible on mobile/tablets where `:hover` is not available.
4. Matrix quadrants: verify removing decorative watermarks and reducing heights does not break drag-and-drop boundary detection.
5. Dark mode: ensure neutral light palette changes do not break high contrast and readability in dark mode.
